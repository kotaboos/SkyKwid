# План исправления недочетов SkyKwid

## Обнаруженные проблемы

### 1. Ошибки в renderer.js
- **Строка 26**: `statusEl` используется до объявления (должен быть после `const statusEl`)
- **Строка 153-167**: Дублирование кода создания `previewWrapper` - создается дважды
- **Строка 271-277**: Комментарий в коде `// async function selectBackground` не закрыт должным образом
- **Строка 495-502**: Дублирование логики отслеживания активного фона
- **Строка 551**: Нет проверки на `null` при `localStorage.getItem('currentBackground')`
- **Строка 554**: `applyBackground` вызывается без проверки существования файла

### 2. CSS недочеты
- **Строка 448-478**: Закомментированный код переключателя (switch) - оставлен мусор
- **Строка 475**: Отсутствует закрывающая скобка для комментария
- **Нет стилей для `empty-playlist`** - класс используется в HTML, но стили не определены

### 3. Проблемы в main.js
- **Строка 51-53**: `icon.png` может отсутствовать в папке `images`

### 4. HTML недочеты
- **Строка 7**: Пустой `div.drag` занимает весь экран и может мешать кликам
- **Строка 62**: Кнопка "Плейлист" не имеет класса `active` по умолчанию

### 5. Отсутствующий функционал
- Нет кнопки "Сохранить как..." для экспорта плейлиста
- Нет поиска по плейлисту
- Нет сортировки песен
- Нет поддержки других форматов (`.wav`, `.flac`, `.aac`)

## План исправлений

### Шаг 1: Исправить renderer.js
- Переместить объявления элементов DOM выше их использования
- Удалить дублирование кода создания `previewWrapper`
- Удалить закомментированный код `selectBackground`
- Упростить логику `applyBackground`
- Добавить проверку существования сохранённого фона перед применением

### Шаг 2: Исправить style.css
- Удалить закомментированный код переключателя (строки 448-478)
- Добавить стили для `empty-playlist`
- Проверить все стили на полноту и корректность

### Шаг 3: Добавить недостающий функционал
- Добавить поддержку `.wav`, `.flac`, `.aac` форматов
- Добавить поиск по плейлисту
- Добавить сортировку песен (по названию, артисту, дате)

### Шаг 4: Улучшить HTML
- Убрать или улучшить `div.drag` блок
- Добавить класс `active` кнопке "Плейлист" по умолчанию
- Улучшить структуру модальных окон

## Приоритет исправлений
1. **Критичные**: Ошибки в renderer.js (баги, дублирование)
2. **Важные**: CSS недочеты (комментарии, отсутствующие стили)
3. **Желательные**: Улучшение UX (поиск, сортировка)
4. **Опциональные**: Поддержка новых форматов
